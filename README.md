# Minha Biblioteca
API desenvolvida em Go que gerencia a minha biblioteca de livros que tenho em casa, com o objetivo de me ajudar a mensurar quais livros eu já tenho, quais já li e etc.


# Rotas
<b>GET</b> /livros <br>
<b>POST</b> /livros <br>
<b>PUT</b> /livros/:id/lido <br>
<b>GET</b> /estatisticas
